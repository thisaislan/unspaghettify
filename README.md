  > Written by a simple developer, **Unspaghettify** is a live exploration of game development architecture, refactoring, and packaging. It uses a simple Unity project to demonstrate a path of incremental improvement — sharing what changes, why it changes, and the reasoning behind each decision. Drawing inspiration from *Bob Nystrom's Game Programming Patterns*, the project aims to fill a gap in discussions about the "middle ground" of game architecture: not just high-level concepts, but the practical, experience-rich thinking that keeps projects healthy and developers sane. It's not a tutorial, but an open conversation about where to put what, and the whys along the way. *Oh, and yes — there's more to game projects than managers, singletons, and spaghetti. But to find that out, we need to talk a little more.*
